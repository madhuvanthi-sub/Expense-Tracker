# Expense-Tracker

A desktop expense tracking application built using Python,
Tkinter, SQLite and Matplotlib.

## Features

- Add expenses
- Edit expenses
- Delete expenses
- Categorize expenses
- Monthly expense totals
- Category pie charts
- Monthly bar charts
- Export expenses to CSV
- SQLite database

## Technologies

- Python
- Tkinter
- SQLite
- Matplotlib

## How to Run

1. Clone the repository
2. Create a virtual environment
3. Install dependencies
4. Run gui.py
